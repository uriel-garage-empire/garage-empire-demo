# GARAGE EMPIRE browser demo

Free static demo of the car-management prototype. Garage customization, NPC market, repairs and simulated drag races run entirely in the browser.

Progress is stored only in this browser on this device. It does not sync between devices and may disappear if browser site data is cleared. There are no accounts, passwords, multiplayer trades or server-side economy here. In-game prices and the fixed 50 EGP/USD conversion are simulation values, not live market quotes.

The separate full Express/PostgreSQL project is not included in this public demo. No secrets, server code, real accounts or saved user data are included.

Open the published GitHub Pages URL to play. Three.js and fonts load from external CDNs; if Three.js is unavailable, the non-3D game remains usable. Car preview is a simple generated prototype, not realistic vehicle models. Tested locally in desktop Chrome and a mobile-sized viewport, not a physical-phone performance guarantee.
